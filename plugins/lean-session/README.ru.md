# lean-session

[English](README.md) | **Русский**

Держит чаты Claude Code короткими. Длинный чат на каждом запросе заново читает весь свой контекст, поэтому самый дешёвый запрос - в коротком чате. Скилл `handoff` переносит состояние чата в файл, и следующий чат начинается пустым.

## Установка

```bash
claude plugin install lean-session@octrow-skills
```

Или ссылкой в один проект, без установки плагина:

```bash
ln -s /path/to/octrow-skills/plugins/lean-session/skills/handoff .claude/skills/handoff
echo '.claude/skills/handoff' >> .git/info/exclude
```

## Что внутри

| Часть | Что делает |
|---|---|
| `skills/handoff` | На границе шага пишет `.notes/handoff.md` и печатает одну строку для вставки после `/clear`. |
| `skills/handoff/scripts/handoff.sh` | Факты для скилла: ветка, последние коммиты, незакоммиченные и новые файлы. `handoff.sh facts` добавляет список файлов в `.notes/` и «Next step» из последней передачи. |
| `scripts/ci-wait.sh` | Одно ожидание прогона GitHub Actions по номеру прогона или по коммиту. Печатает строку статуса и упавшие джобы. |

## Файл передачи

`.notes/handoff.md`, не больше 40 строк, пять разделов:

- **Next step**: одна команда или действие.
- **State**: блок из скрипта.
- **Decisions**: только ссылки на файлы. Решение, которое живёт только в чате, сначала записывается в файл.
- **Open**: что обещано и не сделано.
- **Rules**: что пользователь велел соблюдать в этом чате.

Заголовки остаются на английском, текст - на вашем языке. Папка `.notes/` убрана из git через `.git/info/exclude`, а не через `.gitignore`. Скрипт работает и в папке без git.

## ci-wait.sh

Запускайте в фоне вместо опроса `gh run view` из чата: модель будит одна итоговая строка.

```bash
scripts/ci-wait.sh owner/repo --sha "$(git rev-parse HEAD)" ci.yml
scripts/ci-wait.sh owner/repo 1234567890
```

Код выхода 0 - прогон прошёл.

## Как попросить

- «передай в новый чат»
- «контекст большой, продолжим в новом чате»

## Что нужно

bash и git; `gh` для `ci-wait.sh`.
