# qt-app

[English](README.md) | **Русский**

Скилл, который с нуля делает десктопный GUI на PySide6 для Python-проекта или добавляет новый экран в готовое Qt-приложение. Пара к [qt-ui](../qt-ui/README.ru.md).

## Установка

```bash
claude plugin install qt-app@octrow-skills
npx skills add octrow/octrow-skills --skill qt-app -g
```

## Что делает

1. Проверяет, можно ли звать ядро в процессе.
2. Запускает ядро на asyncio-цикле в отдельном потоке, результаты идут через Qt-сигналы.
3. Ставит из готового шаблона: extra `gui`, команду `<app> gui`, окно с боковым меню и свою светлую и тёмную тему на токенах.
4. Строит экраны по одному, сначала тест pytest-qt офскрин. Тексты и вызовы общие с CLI.
5. Передаёт скриншоты обеих тем в qt-ui для правки вёрстки.
