# План: находки карты логики lean-spec

Находки из составления `docs/logic-map.md` 2026-11-02 и из независимого ревью карты.
Карта описывает скилл как он есть; этот файл говорит, что в нём не так и что предлагаем. Новые находки дописываются в конец.
Исправленная находка получает ✅, карта правится в том же коммите.

Важность: HIGH - неверный результат для пользователя. MEDIUM - результат хуже, чем мог бы быть. LOW - шум, долг, документация.
«Вопрос» - баг или так задумано, решает автор. «Не подтверждено» - нужен живой прогон.

Пути ниже - от `plugins/lean-spec/skills/lean-spec/`.
