# lean-spec

[English](README.md) | **Русский**

Скилл, который проверяет кусок логики по короткой модели на Lean 4 или ускоряет его с доказательством, что результат не меняется.

## Установка

```bash
claude plugin install lean-spec@octrow-skills
npx skills add octrow/octrow-skills --skill lean-spec -g
```

Только Linux. Нужны Lean 4.35 (elan) и bubblewrap.

## Как это устроено

- Формулировки теорем утверждаются и замораживаются.
- Доказательства проверяет ядро Lean.
- Прод-код (сначала Python) сверяется с моделью как с оракулом через Hypothesis.

## Что покрывает

- Быстрый путь получает теорему «быстро = эталон при инварианте», проверку во время работы и откат. Пример: lean-derive-hargup (280 тыс. пользователей на VPS за $12).
- Цикл повторов или автомат состояний получает доказанные свойства безопасности при любой последовательности сбоев.
- Ограничитель частоты или квота получает доказанную ёмкость, например сколько попыток с одного IP за сутки.
- Правила можно брать из шага карты логики. Каждая теорема цитирует свою строку, а всё, что карта оставляет размытым, становится находкой.
