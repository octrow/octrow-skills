# system-design

[English](README.md) | **Русский**

Скилл, который проектирует или проверяет архитектуру бэкенда по цифрам.

## Установка

```bash
claude plugin install system-design@octrow-skills
npx skills add octrow/octrow-skills --skill system-design -g
```

## Что делает

1. Начинает с требований.
2. Считает на салфетке скриптом: из DAU в запросы в секунду, app-серверы, память под кэш, чтения и записи в БД, реплики, шарды, объём хранилища, исходящий трафик.
3. Берёт самую низкую ступень лестницы масштабирования, которая выдерживает эти цифры.
4. Выбирает движок хранения и паттерн кэша под характер доступа.
5. Пишет план на случай отказов и называет компромиссы вслух.

Если репозиторий уже есть, скилл сначала читает реальный стек и метрики.

## Что спросить

- «выдержит ли этот FastAPI 2 млн DAU на одной VPS?»
- «спроектируй бэкенд фотохостинга на 20 млн DAU»
