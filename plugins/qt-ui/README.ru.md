# qt-ui

[English](README.md) | **Русский**

Скилл для визуальных правок в десктопном приложении на PySide6 / PyQt6.

## Установка

```bash
claude plugin install qt-ui@octrow-skills
npx skills add octrow/octrow-skills --skill qt-ui -g
```

## Что делает

1. Снимает каждый экран офскрин в светлой и тёмной теме.
2. Составляет список дефектов: обрезанный текст, сжатые колонки таблиц, отступы мимо сетки, полужирный, который не рисуется.
3. Правит их через токены темы проекта по образцу соседнего экрана, где уже сделано правильно.
4. Сравнивает снимки до и после попиксельно, чтобы общая правка QSS не сломала тихо другой экран.

В справочнике собраны особенности Qt, которые выглядят как ошибки дизайна:

- подписи выше полей;
- колонки, сжатые до букв;
- полужирный, который рисуется обычным.

Запуск без задачи берёт список открытых дефектов проекта.

## Что попросить

- «GUI кривой, найди, что не так на всех экранах»
- «отчёт не влезает в маленькое окно»

Работает в паре с [qt-app](../qt-app/README.ru.md).
