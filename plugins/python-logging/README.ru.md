# python-logging

[English](README.md) | **Русский**

Скилл, который настраивает, чинит или улучшает логирование в Python-проекте.

## Установка

```bash
claude plugin install python-logging@octrow-skills
npx skills add octrow/octrow-skills --skill python-logging -g
```

## Что делает

- Задаёт один бюджет на все логи с ротацией по размеру.
- Пишет широкие события: одна JSON-строка на запрос, сообщение или задачу.
- Маскирует секреты в строках лога.
- Держит запись в одной строке, чтобы journald её не разрезал.
- Добавляет тесты, которые доказывают потолок.

## Что попросить

- «логи забили диск, ограничь их 1 ГБ»
- «по логам непонятно, что случилось с задачей 42»
