# gui-state-map

[English](README.md) | **Русский**

Скилл, который строит карту GUI по экранам × состояниям × действиям и подтверждает каждый шаг скрином и diff'ом.

## Установка

```bash
claude plugin install gui-state-map@octrow-skills
npx skills add octrow/octrow-skills --skill gui-state-map -g
```

## Что делает

1. Пишет план: безопасный стенд на живых данных, классы кликов (чтение, запись, квота, система), матрицу состояний.
2. Читает каждую кнопку из кода: обработчик, что пишет, что запускает, что должно поменяться на других экранах.
3. Проходит матрицу скриптами: скрин, текст страницы и diff данных до и после каждого клика.
4. Сводит `map.md` с графами состояний и процессов. Находки идут в `findings.md`, по ходу ничего не чинится.

Веб снимается через Playwright. Десктоп снимается через офскрин-драйвер тестов и живой запуск с X11-инструментами.
