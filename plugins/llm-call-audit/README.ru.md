# llm-call-audit

[English](README.md) | **Русский**

Скилл, который проходит по всем вызовам моделей в коде и для каждого ищет самый дешёвый вариант без потери качества.

## Установка

```bash
claude plugin install llm-call-audit@octrow-skills
npx skills add octrow/octrow-skills --skill llm-call-audit -g
```

## Что делает

Для каждого вызова он предлагает один из вариантов:

- обычный код;
- классификатор TypeSafe/Jev;
- более дешёвую или более сильную LLM;
- сокращённый промпт;
- исправленный маршрут в шлюзе.

Цифры он берёт из логов приложения, кэша ответов LLM и логов шлюза. Он пишет отчёт и ничего не меняет.
