# logic-map

[English](README.md) | **Русский**

Скилл, который пишет, обновляет и сверяет с кодом `docs/logic-map.md`: один файл, который агент читает первым.

## Установка

```bash
claude plugin install logic-map@octrow-skills
npx skills add octrow/octrow-skills --skill logic-map -g
```

## Что показывает карта

По шагам:

- где основной поток делится;
- что решает каждый шаг;
- что меняется без LLM, сети или ключа;
- как шаг падает;
- какой модуль его делает.

## Что скилл делает дальше

Найденные ошибки логики уходят в нумерованный план. Код скилл не трогает.

Карту не дают устареть два правила: «карта в том же коммите» в `AGENTS.md` и тест на строки `Module:`.
